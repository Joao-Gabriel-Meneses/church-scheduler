# StatCard
Cartão de indicador: rótulo, número grande (`stat`), contexto embaixo e seta ↗ para o detalhe.

- `rt-panel` plano (`canvas`, borda `surface` 2px, `radius-lg`).
- Painel do gerente: Eventos no mês, Vagas preenchidas, Sem resposta (leva ao painel de quem não respondeu), Maior carga.
- O subtítulo dá a proporção ou a divisão ("de 18 · 2 vazias"). Nada de variação percentual inventada.
