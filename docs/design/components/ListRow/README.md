# ListRow
Linha clicável: tile de ícone 48px, título + subtítulo e chevron — para listas de cadastro e navegação.

- Usos: habilitações do membro (função + nível), modelos de evento, funções do ministério, atalhos do painel.
- `__title` em `body-lg`, `__sub` em `label`/`ink-muted` com o dado que importa ("3 escalas em outubro").
- `--tint` para o item selecionado. Empilhe com `rt-list` (`space-2`).
