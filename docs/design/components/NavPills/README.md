# NavPills
Navegação principal no topo: pílulas brancas com ícone de 16px + rótulo; a atual fica escura.

- Markup: `<nav class="rt-nav">` com `<a class="rt-nav__item">`; a página atual com `aria-current="page"`.
- Gerente vê: Escalas, Disponibilidade, Membros, Regras. Membro vê: Minhas escalas, Disponibilidade. Admin ganha Ministérios e Auditoria.
- No celular, a nav vira barra inferior com os mesmos itens (ícone + rótulo curto).
