# Badge
Etiqueta de estado ou atributo, em pílula de 28px.

- Estado da escala: `--draft` (Rascunho, tracejado), `--published` (Publicada, ponto `brand-strong`). Republicar volta para Rascunho até publicar de novo.
- `--locked`: período com disponibilidade travada. `--alert`: contagem de problemas.
- Neutra (`surface`): nível (Iniciante/Experiente). Ministério: fundo `tint-mint`/`tint-rose`/`tint-lemon`.
