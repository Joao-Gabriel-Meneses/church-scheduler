# Calendar
Mês em grade: dias com evento marcados com ponto `brand`; seleção de intervalo em faixa escura contínua.

- Markup: `rt-cal` > `__head` > `__grid` (7 colunas, semana começa na segunda). `__day--event` para dias com culto/evento; `--out` fora do mês.
- Intervalo (período de trava, relatório): `__day--in` + `--start`/`--end` por semana.
- Usos: criar evento avulso, escolher período de relatório, visão mensal de "minhas escalas".
